Privacy Policy

Neon Galaksi 3D by Efendi Games (Hilmi Salih Altınışık), contact altinisikhilmisalih@gmail.com. The game is fully playable offline and without an account; no personal information is requested. For online features we only store a random guest ID, an optional nickname, game progress, scores and run summaries, your Google ID / e-mail only if you link it, and error logs (app version, device model, Android version, error message, game state; kept 90 days). No ads, no purchases, no tracking. The Android app only requests Internet and Vibrate. Data is stored in the EU (Supabase, Frankfurt) over HTTPS, never sold. Delete everything in Settings → Account → DELETE ACCOUNT or via the deletion request page. Not directed at children under 13.
